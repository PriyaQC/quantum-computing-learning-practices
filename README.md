
# Quantum Computing Learning Practice

This repository contains my hands-on practice as an Applied Mathematics undergraduate building foundations in programming and quantum computing.

## Topics

* Python fundamentals and functions
* NumPy and linear algebra
* Quantum states and gates
* Measurement and entanglement concepts
* Introductory Qiskit circuits
* Visualisation with Matplotlib

## Folder Structure

* `01-python-fundamentals/`
* `02-numpy-and-linear-algebra/`
* `03-quantum-states-and-gates/`
* `04-measurement-and-entanglement/`
* `05-qiskit-practice/`

## Tools

Python, NumPy, Matplotlib, and Qiskit.

## Goal

To strengthen my mathematical and programming foundations for further study in quantum mechanics, quantum computing, and quantum information.

This is a learning repository containing practice exercises and simulations, not original research.
